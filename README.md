## Задача

Реализовать Python-пакет с предметной моделью и каталогом объектов:

- **сущность `Book`** - библиотечная книга на `@dataclass(frozen=True)` с проверкой инвариантов при создании: `item_id`, `title`, `category`, `year`, `author`, `copies`;
- **каталог `LibraryCatalog`** - методы `add`, `get`, `remove`, `find_by_category`, `find_by_name`, `__len__`, `__iter__`, `__contains__`; поиск по ID через словарь, запрет дубликатов, детерминированный порядок итерации;
- **хранение** - сохранение и загрузка в JSON с полем `format_version` в корне; повреждённый документ не меняет существующий каталог;
- **исключения** - базовое `CatalogError` + 5 наследников.

## Каталог поддерживает

- Хранение книг в `dict[int, Book]` - поиск по ID за O(1).
- Порядок итерации - по возрастанию `item_id` (числа).
- Поиск по категории - точное совпадение, без учёта регистра.
- Поиск по имени - подстрока в `title`, без учёта регистра.
- Пустой запрос возвращает `[]`.
- Методы поиска возвращают **новый** список (внутренний не отдаётся).
- Дубликат ID запрещён - `DuplicateIDError`.
- Удаление отсутствующего ID -> `ObjectNotFoundError`.
- `__contains__` принимает только `int` (не `str`, не `bool`).

## Сущность `Book` поддерживает

- `@dataclass(frozen=True)` - объект неизменяем после создания.
- Инварианты проверяются в `__post_init__`; при нарушении - `IncorrectEssenceError`.
- `item_id` - целое `>= 1`.
- `title`, `category`, `author` - непустые строки.
- `year` - целое `<2027`.
- `copies`- целое `>= 1`.
- `to_dict` / `from_dict` для сериализации.
- `from_dict`: проверяет наличие обязательных полей, лишние ключи игнорирует.

Ошибки: `item_id <= 0`, `item_id` не число, пустые строки, `year > 2027`, `copies <= 0`, в `from_dict` отсутствуют поля.

## Ошибки

| Исключение | Когда возникает |
|------------|-----------------|
| `IncorrectEssenceError` | сущность не прошла инварианты |
| `DuplicateIDError` | `add` с уже существующим `item_id` |
| `ObjectNotFoundError` | `get` / `remove` по отсутствующему ID |
| `UnsupportedFormatError` | `load` файла с неизвестной `format_version` |
| `DamagedFileError` | битый JSON, неверная структура, невалидный элемент, дубликат ID в файле |

Все - наследники `CatalogError.

## Алгоритм работы каталога

Каталог хранит книги в `dict[int, Book]` по `item_id`.

Сохранение:

```
catalog.to_json() -> json.dumps  ->  запись в файл
```

Загрузка:

```
чтение файла -> json.load  ->  проверка format_version -> построение нового LibraryCatalog  ->  возврат
```

`load` - classmethod, строит новый каталог. 
При любой ошибке (битый JSON, неверная версия, невалидный элемент, дубликат ID) выбрасывается предметное исключение, а исходный каталог не меняется.

## Принятые решения

- **`item_id: int`** - целое `>= 1`. Уникальность и поиск через `dict[int, Book]` (O(1)).
- **`frozen=True`** - сущность иммутабельна: ключ словаря не может разойтись с `item_id` после `add`; инварианты гарантированы на всё время жизни.
- **Порядок итерации** - по возрастанию `item_id`, детерминирован.
- **Поиск**: `find_by_category` и `find_by_name` - точное совпадение. Оба независимы от регистра.
- **`save`** - сериализация в память до открытия файла.
- **`load`** - classmethod, строит новый каталог; при ошибке исходный не меняется.
- **`format_version`** - пишется в корень JSON, проверяется при загрузке.
